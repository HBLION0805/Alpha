# Macro psychology extension V1

Task: integrate the Owner's second education batch into the existing Macro
playbook. This is a bounded educational and voluntary reflection extension, not
a psychological assessment or a strategy change.

## Design and acceptance

- Add twenty attributed entries, a seventeen-bias reference and nine optional
  questions grouped before entry, while holding and after a decision. Preserve
  the original thirty entries and twelve worksheet fields.
- An explicit question button appends that question to the existing personal
  reflection draft. It must preserve other fields, never save automatically,
  invalidate an earlier preview/request ID and reject overflow without truncation.
  Selecting a question does not assert the user has that bias.
- Keep the V1 note/assessment contract. New catalogs carry an explicit content
  revision and copy the new reference material. Old notes recover from their
  original catalog, without adding new material or changing fingerprints.
- Separate optional process prompts, untested thresholds and rejected claims.
  Retain both conflicting 30/30 variants with unresolved time anchors. No new
  threshold, cooldown, detector, sizing multiplier or confidence score.
- Treat source instructions, books, military metaphors, platform preferences and
  political classifications as supplied material. No social account creation,
  follow, feed, timer, purchase, broker migration or watchlist expansion.
- Sources: the supplied prose and two images; SEC-hosted Library of Congress
  behavioral summary; publisher descriptions of the two books. Full books and
  the image's entire empirical claims are not represented as verified. The
  public Truth Social page is an unverified-content reference if unreadable.
- Preserve all frozen study inputs, canonical guidance, capital policy, evidence
  gates, source cadence, saved notes and private records. Archive supplied images
  privately under the existing ignored runtime tree with receipt/hash metadata.

## Content distinctions

Useful reflection: entry discomfort versus evidence, breakeven fixation,
revenge/FOMO, contrary evidence, ticker attachment, independent direction checks,
whole-position exposure, time constraints, controllable decisions, process versus
outcome and original contemporaneous reasoning. All are questions, not diagnoses.

Candidate only: 72 hours, the two 30/30 definitions, one loser addition, winner
additions, breakout/retest timing and claims about the final thirty seconds.
Rolling realizes the old result and opens new exposure; it does not erase losses.

Exclude as facts/rules: guaranteed weekly returns, unsupported population win
rates or universal trading hours, options as guaranteed principal protection,
personality/health/cultural judgments of earning ability, manipulation accusations
without evidence, political midpoint as truth, and confidence as an automatic
position-size input. Market series are not assumed independent coin flips.

## Validation

Focused checks cover legacy copied-catalog recovery and exact retry, new catalog
copy isolation, prompt append/overflow, escaped rendering and unchanged assessment
despite emotional prose. Existing protected save tests remain. Run strict typecheck,
aggregate validation and desktop/mobile UI checks. Use synthetic workspaces for
save tests; no invented production notes or behavior assessments.
