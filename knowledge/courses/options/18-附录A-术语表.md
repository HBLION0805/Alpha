# 附录 A 术语表

按首次出现的章节排列，含英文。

## 第 1 章

* **看涨期权（Call）/ 看跌期权（Put）**：以执行价买入 / 卖出标的的权利。
* **执行价（Strike）**：行权时的买卖价格。
* **到期日（Expiration）**：合约失效的日期。
* **乘数（Multiplier）**：一张合约对应的标的数量，美股为 100。
* **权利金（Premium）**：期权的价格；买方的最大亏损、卖方的最大盈利。
* **内在价值（Intrinsic Value）**：立刻行权能得到的价值。
* **时间价值（Extrinsic / Time Value）**：权利金减内在价值。
* **价内 / 平值 / 价外（ITM / ATM / OTM）**：有内在价值 / 执行价最接近现价 / 无内在价值。
* **到期盈亏图（Payoff Diagram）**：到期时标的价格与盈亏的关系图。
* **盈亏平衡点（Breakeven）**：到期盈亏为零的标的价格。
* **波动率风险溢价（Volatility Risk Premium, VRP）**：隐含波动率长期高于实际波动率的现象。
* **期权清算公司（OCC）**：美股期权的中央对手方。
* **零日期权（0DTE）**：当天到期的期权。

## 第 2 章

* **美式 / 欧式（American / European）**：可随时行权 / 只能到期日行权。
* **实物交割 / 现金结算（Physical / Cash Settlement）**：行权后交割股票 / 按差额结算现金。
* **行权（Exercise）/ 指派（Assignment）**：买方执行权利 / 卖方被要求履约。
* **自动行权（Exercise by Exception）**：到期时价内 0.01 美元以上自动行权。
* **钉住风险（Pin Risk）**：到期时标的在执行价附近，卖方不确定是否被指派。
* **除息日（Ex-dividend Date）**：股息从股价中扣除的日期；深度价内看涨在此前可能被提前行权。
* **买卖价差（Bid-Ask Spread）**：买价与卖价之差；期权的主要交易成本。
* **未平仓量（Open Interest, OI）**：未平仓的合约数。
* **现金担保 / 备兑（Cash-secured / Covered）**：以全额现金 / 以持有的股票担保的卖出。
* **裸卖（Naked / Uncovered）**：无担保、无保护腿的卖出。
* **Reg T 保证金 / 组合保证金（Portfolio Margin）**：逐笔计算 / 按组合风险计算的保证金制度。
* **价差单（Spread Order）**：多腿同时成交的订单。
* **1256 合约**：美国税法下享受 60/40 待遇的宽基指数期权等。
* **洗售规则（Wash Sale）**：30 天内买回实质相同证券时亏损不能立即抵扣。
* **SPX / SPY / XSP / NDX / QQQ**：标普 500 指数期权 / ETF 期权 / 迷你指数期权；纳斯达克 100 指数期权 / ETF 期权。
* **上午结算 / 下午结算（AM / PM Settlement）**：按开盘价 / 收盘价结算。

## 第 3 章

* **Black-Scholes**：期权定价的基础模型。
* **σ√T**：波动率乘以时间平方根；时间价值的核心。
* **买卖权平价（Put-Call Parity）**：C − P = S − PV(K) − PV(D)。
* **合成头寸（Synthetic）**：用期权和标的复制另一种头寸。
* **隐含波动率（Implied Volatility, IV）**：从期权价格反解出的波动率。
* **预期变动（Expected Move）**：S × IV × √(T)；市场定价的一个标准差变动。
* **触及概率（Probability of Touch）**：到期前曾触及执行价的概率，≈ 2 × Delta。

## 第 4–5 章

* **Delta**：期权价格对标的价格的敏感度；也是对冲比率和价内概率。
* **Gamma**：Delta 对标的价格的敏感度。
* **Theta**：期权价格对时间的敏感度（每日）。
* **Vega**：期权价格对隐含波动率的敏感度（每 1 个点）。
* **Rho**：期权价格对利率的敏感度。
* **Beta 加权 Delta**：把不同标的的 Delta 换算为 SPY 等价股数。
* **Delta–Gamma 近似**：盈亏 ≈ Δ·ΔS + ½Γ·ΔS²。
* **Gamma 剥头皮（Gamma Scalping）**：持有正 Gamma 并对冲 Delta 以赚取实际波动。
* **IV 压缩（IV Crush）**：事件后隐含波动率塌陷。
* **Vanna / Charm / Volga**：Delta 对 IV / Delta 对时间 / Vega 对 IV 的敏感度。
* **LEAPS**：一年以上到期的期权。

## 第 6 章

* **实际波动率（Realized / Historical Volatility, RV）**：标的实际发生的波动。
* **IV Rank / IV Percentile**：当前 IV 在过去一年区间的位置 / 低于当前值的天数占比。
* **期限结构（Term Structure）**：不同到期日的 IV；正向 / 倒挂。
* **偏度（Skew）/ 微笑（Smile）**：不同执行价的 IV 差异。
* **风险反转（Risk Reversal）**：25 Delta 看跌 IV 减 25 Delta 看涨 IV；偏度的度量。
* **波动率曲面（Volatility Surface）**：执行价 × 到期日 × IV。
* **VIX**：标普 500 未来 30 天的隐含波动率指数。
* **特殊开盘计算值（SOQ）**：VIX 期货与期权的结算价。
* **事件方差（Event Variance）**：期权定价中归因于某个事件的部分。

## 第 7–11 章

* **借记价差 / 信用价差（Debit / Credit Spread）**：净付出 / 净收入的垂直价差。
* **牛市看跌价差 / 熊市看涨价差（Bull Put / Bear Call Spread）**：看多 / 看空的信用价差。
* **比率价差 / 反向比率价差（Ratio / Backspread）**：买卖数量不等的价差。
* **穷人的备兑（PMCC）**：LEAPS 看涨 + 卖出短期看涨的对角价差。
* **备兑开仓（Covered Call）/ 现金担保卖沽（Cash-secured Put）/ 轮子（Wheel）**：卖方的三种基本策略。
* **跨式 / 宽跨式（Straddle / Strangle）**：同执行价 / 不同执行价的看涨加看跌。
* **铁鹰 / 铁蝶（Iron Condor / Iron Butterfly）**：定义风险的卖出宽跨式 / 跨式。
* **蝶式（Butterfly）**：1-2-1 结构，赌精确目标。
* **日历 / 对角价差（Calendar / Diagonal）**：不同到期日、同 / 不同执行价。
* **Delta 中性（Delta Neutral）**：组合 Delta 接近零。
* **反向铁鹰（Reverse Iron Condor）**：买入两侧价差，赌大动。
* **保护性看跌（Protective Put）/ 领口（Collar）**：持股 + 买看跌 / 再加卖看涨。
* **推定卖出（Constructive Sale）**：税法概念，领口过紧可能触发。
* **尾部保护（Tail Hedge）**：为极端下跌买的保险。
* **变现（Monetize）**：保护盈利后卖出并买入被抛售资产。

## 第 12–16 章

* **组合 Greeks（Portfolio Greeks）**：所有仓位 Greeks 的汇总。
* **情景矩阵（Scenario Grid）**：标的变动 × IV 变动的盈亏表。
* **滚动（Roll）**：平仓并开一个相似但期限或执行价不同的仓位；向外 / 向上 / 向下。
* **名义敞口（Notional Exposure）**：合约数 × 执行价 × 100。
* **压力测试（Stress Test）**：−20% 跳空、IV 翻倍、复合三情景。
* **保证金螺旋（Margin Spiral）**：IV 上升 → 保证金上升 → 强平 → IV 再升。
* **三句话（Three Sentences）**：方向 / 幅度与时间 / 波动率。
* **策略选择矩阵（Strategy Matrix）**：方向观点 × IV 环境 → 结构。
* **三维归因（Three-dimensional Attribution）**：每笔交易在方向、时间、波动率上各赢或输。
* **期望值（Expectancy）**：胜率 × 平均盈利 − 败率 × 平均亏损。
* **离散度交易（Dispersion）**：卖指数波动率、买成分股波动率。
* **方差互换（Variance Swap）**：以实际方差与约定方差之差结算的合约。
* **自动赎回产品 / 雪球（Autocallable）**：隐含卖出向下敲入看跌期权的结构性产品。
