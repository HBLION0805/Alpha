# 附录 D 四份模板

## D.1 策略选择矩阵（完整版）

**第一步：三句话。**

```
方向：我认为标的会 ______（涨 / 跌 / 不动 / 大动但方向不明）
幅度与时间：在 ______ 天内，变动 ______% 以上 / 以内
波动率：当前 IV Rank ______，隐含 ______ vs 实际 ______；我预期 IV 会 ______（升 / 降 / 不变）；
        事件 ______（日期），事件前后 IV 会 ______
```

**第二步：IV 环境。** 低（IV Rank < 25 且隐含 ≤ 实际）/ 中 / 高（IV Rank > 50 且隐含 > 实际）。冲突时以"隐含 vs 实际"为准。

**第三步：查矩阵。**

| 方向观点 \ IV 环境 | 低 IV | 中 IV | 高 IV |
| --- | --- | --- | --- |
| 看涨 | 买入看涨（Δ0.5–0.7）；LEAPS | 看涨借记价差；PMCC | 看跌信用价差；现金担保卖沽；备兑（若持股） |
| 看跌 | 买入看跌；看跌借记价差 | 看跌借记价差 | 看涨信用价差 |
| 中性（不大动） | 不做；或日历（做多远月 Vega） | 小仓位铁鹰 | 铁鹰；铁蝶 |
| 大动、方向不明 | 买入跨式 / 宽跨式 | 反向铁鹰 | 不做；有事件则日历 |
| 对冲持仓 | 保护性看跌；VIX 看涨 | 看跌价差 | 领口；看跌价差 |

**第四步：事件叠加。** 到期前有事件（财报 / FOMC / CPI）时：
- 看涨或看跌 → 用价差剥掉 Vega；或用事件后到期的期权、事件后入场。
- 中性 → 事件后立即到期的铁鹰（翼在历史最大变动之外）或日历。
- 大动 → 事件后到期的跨式，在 IV 抬升前买入；或反向铁鹰。
- 事件前不买单腿、不卖单腿。

**第五步：例外检查。**
- 流动性（OI < 1000 或价差 > 10%）→ 只做单腿或不做。
- 账户小 → XSP / SPY 代替 SPX；价差代替单腿卖出。
- 持有股票 → 优先备兑 / 领口。
- 指数判断 → 考虑 SPX / XSP 的 1256 待遇。

**第六步：Greeks 核对。** 选出的结构在方向 / 时间 / 波动率上的符号（附录 B）是不是三句话里想要的？不是 → 换。

**第七步：默认输出是"不做"。** 三句话写不全、IV 环境不匹配、例外触发 → 不做。

## D.2 期权仓位规则卡

```
═══════════════════════════════════════════
期权仓位规则卡
生效日期：              下次修订（季度复盘日）：
═══════════════════════════════════════════

【买方】
单笔权利金 ≤ 账户的 ____%（0.5–2%）
所有买方权利金之和 ≤ ____%（5–10%）
尾部保护年度预算 ____%（1–2%），单列，覆盖账户 1–2 倍名义价值

【定义风险的卖方】
单笔最大亏损 ≤ ____%（1–2%）
所有卖方最大亏损之和 ≤ ____%（10–20%）
单一标的的最大亏损 ≤ ____%（3–5%）
共同赌注（同方向所有卖方仓位）的最大亏损之和 ≤ ____%（3–5%）
权利金 ≥ 翼宽的 ____%（20%）

【未定义风险的卖方】
□ 不做
□ 做，但：单笔压力测试损失（−20%，IV 翻倍）≤ ____%（2–3%）；
  总名义敞口 ≤ 账户的 ____%（50%）；只用可用保证金的 ____%（50%）以下

【组合】
Theta ≤ 账户的 ____% / 天（0.1–0.2%）
Beta 加权 Delta ≤ ____ 股 SPY 等价（对应杠杆 ____ 倍）
Vega：IV +10 的损失 ≤ ____%

【压力测试】（每周 ____）
−20% + IV +30：损失 ____%，上限 ____%（10–15%）
IV 翻倍：损失 ____%，上限 ____%（5%）
复合：损失 ____%，上限 ____%（15–20%）
超过上限 → 当周减仓

【流动性】
只交易 OI > ____ 、价差 < ____% 的合约
规模大的仓位用指数期权

【实务】
到期日收盘前平掉距现价 1% 内的空头
除息日前检查空头看涨（时间价值 < 股息 → 平或滚）
临期平值空头不过周末
财报前不卖单腿、不买单腿
到期 ≤ 7 天的单腿只在有明确事件判断时做，仓位按彩票算

【调仓】
每个仓位最多调整 ____ 次（1）
滚动不增加合约数或最大亏损
滚动前过检验五问

【心理触发】
连胜超过 ____ 次（10）→ 强制压力测试 + 复核本卡
一笔大赚之后 → 下一笔仓位不增加

【铁律】
本卡只在季度复盘日修改
盈利后不放宽任何数字
"这次不一样"不是修改本卡的理由
═══════════════════════════════════════════
```
