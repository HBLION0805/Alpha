# M10 — Belt and Road Initiative

研究日期2026-09-20（America/New_York），Codex/Alpha整理与同人自审，非独立审核。范围：政策边界、融资分类、中老铁路与汉班托塔港两个异质案例。禁止runtime使用；没有新项目库或知识审批。

## A. Executive definition

BRI是2013年提出的合作倡议和政策框架，不是一个统一债权人、贷款合同或项目公司。官方2023白皮书把它解释为互联互通与共同发展；这属于OFFICIAL_STATEMENT，项目成效需独立核验。[S01] World Bank历史研究指出，中国与相关经济体的贸易和承包联系早于2013；不能把后来称BRI的所有项目都说成2013后新建。[S02]

本批把“倡议归属”“业主/借款人”“承包/运营方”“债权人及融资工具”分开。中国企业境外施工不自动等于中国政府贷款；贷款、股权、援助、特许经营也不自动互相转换。只有具体文件支持才赋予BRI归属，不把M09 Lobito等所有跨境铁路纳入。

## E. Flows

融资类型是合同分类，不是假定每个案例都具备全部类型。

| 类型 | 资金/权利流向与会计边界 |
|---|---|
| Grant | 无需偿还本金的转移；有采购/用途条件仍不是无条件现金。承诺与到账分开 |
| Concessional loan | 贷款含优惠成分；利息/宽限期/币种须核。优惠贷款仍有债务 |
| Commercial loan / policy-bank lending | 前者描述条款性质，后者描述债权人；政策银行贷款未必优惠 |
| SOE investment / equity | 购买股份或出资，承担剩余权益风险；SOE身份不使每笔投资成为援助 |
| PPP / BOT | 风险分配与运营合同，不是单一融资工具；可同时有股权、商业贷款及担保 |
| Host-government borrowing | 主权借款人直接债务；用于给SPV注资时，“项目有股本”不代表政府没有借债 |
| Project / SOE / sovereign / guaranteed debt | 分别标借款主体、追索权和担保；不能把全部项目债直接算主权，也不能遗漏或有担保 |
| CAPITAL_COMMITMENT → CAPITAL_DISBURSEMENT →建设FLOW →运营FLOW | 依次核授信、提款、支付、验收、收费；合同总价不是每期现金，租赁现金也不等于新产能 |

以上分类用于阅读S02/S03/S06/S09；不是本批核证的一张全球BRI资金总账。

## F. Causal mechanisms

**SUPPORTED_MECHANISM：基础设施 → 可达性/运输成本 → 贸易。** 只有货源、支线、通关、定价和可靠性配套时，才能把能力变成有效运输。World Bank的模型收益依赖政策改革，不能当所有项目已实现的回报。[S02/S03]

**CONDITIONAL_HYPOTHESIS：融资 → 增长和外汇 → 还款。** 如果收入币种与债务不匹配、货量不足或成本超支，即使社会便利提高，项目仍可能无法按期偿债。国家其他债务、汇率和财政也影响结果，不能只盯一个项目。[S05/S09]

**ALPHA_INFERENCE：利益分配 → 政治反弹/安全成本。** 净社会收益与某群体净损失可以并存；征地、岗位与环境争议需地方证据。安全事故、抗议与战争不能互换，更不能由一次争议推断外国策划。

## H. Current structure

2026-06 World Bank老挝更新估计当年债务服务约GDP的13%，这是国家层面预测，不是铁路项目成本或违约率。[S05] 2026铁路/港口材料显示实际运输，推翻“所有基础设施都没有使用”的绝对说法；未证明收入覆盖资本成本。[S04/S08]

汉班托塔运营商另把年处理能力约200万TEU列为2026年底第二阶段目标，不能与2025实际428,036TEU相混。[S08] 老挝现期项目偿债表、汉班托塔最新收费/成本/债务对账均缺。2017法律/合资安排只作为当时事实，未假定此后合同从未改变。
