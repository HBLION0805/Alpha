# M05 — Global Shipping Chokepoints

研究日及来源接收日：2026-09-20（America/New_York）。这是有日期的研究，不是船舶安全指令、当前可通航保证或交易许可。来源编号对应M节；不同资料的观察期不合并为一个“现在”。

## A. Executive definition

咽喉的经济作用是限制某类货物在一定时间、成本和风险下从产地到用户的能力。地图窄不等于可以完全封锁；运河恢复也不等于运费、保险和整个航线已恢复。**VERIFIED** 的地理关系与 **CONDITIONAL** 的市场影响分开。[S01/S02]

必须分清原油/石油液体、LNG、集装箱、干散货，船次、船舶吨位、货重、货值和吨海里。运河净吨位及PC/UMS衡量船舶容积相关规模，不是所运货物重量；桶/日也不能直接变成“全球贸易百分比”。[S01/S04/S05/S11]

### 五处不能互相替代的通道

| 地点 / 主要货流 | 替代路径与成本边界 | 安全、保险、运力约束 |
|---|---|---|
| Hormuz：海湾与阿曼湾/外海之间；原油、成品油、LNG | 部分原油可走沙特/阿联酋管道，但受接入、终点和实际剩余能力限制；船绕好望角不能让仍在海湾的货物越过Hormuz。LNG缺乏同等管道出口替代 | 沿岸军事冲突、船员安全、承保/除外责任与港口装运相互影响；名义管道能力不是当日可用量。S01/S02/S03 |
| Suez：地中海—红海；集装箱、油、散货及部分LNG | 亚欧可绕好望角，增加航程、燃料和占船时间；SUMED只替代部分原油运输，不能替代集装箱或LNG船 | 运河尺度、船型、航道组织；南部红海不安全时运河本身通畅也未必有船。S02/S04 |
| Bab el-Mandeb：红海南口—亚丁湾；油、集装箱及区域贸易 | 亚欧绕好望角可避开；红海内部目的港不一定有同样替代。与Suez串联但沿线港口使两者流量不等 | 袭击、护航、战险与航司自主绕行；安全声明不等于保险或船员同意。S02/S03 |
| Malacca：印度洋—太平洋短程路径；亚洲原油、LNG和一般贸易 | Sunda/Lombok及更远岛链航路，或有限陆上/管道替代；船型吃水、距离、港口能力改变可替代性 | 多沿岸国协作、拥堵和事故；本批未取得当前军事封锁证据，不类比Hormuz现状。S02 |
| Panama：大西洋—太平洋；集装箱、LPG、干散货、油及可通过船型的LNG | 南美绕行或分段海陆转运；增加航程或装卸，不能假设铁路承接全部船货 | 船闸/水位/淡水/吃水与预约约束；本批证据指向水文和能力约束，不据此推断军事中断。S02/S05/S06 |

**SUPPORTED_MECHANISM：**同样少一艘船，缺原油可能影响炼厂投料，缺集装箱可能延迟零部件，水位限载可能仍有船通行但每船少载。统一用“船数下降→全球通胀”会漏掉这些差异。

## F. Causal mechanisms

| Trigger → first → second | Level | Counterforce → observable confirmation → falsification |
|---|---|---|
| 出口通道实质中断 → 装运减少 → 炼厂/进口商寻找替代、价格压力 | WELL_ESTABLISHED物流约束；价格 CONDITIONAL | 库存、其他产地/管道、需求下降；查港口装运与到货、实物价差；若货流未降且供应替代充分，不能用中断叙事解释全部涨价。S01/S02 |
| 绕航 → 单航次天数和燃料增加 → 同船队有效交付频次下降、运价压力 | CONDITIONAL | 闲置船、增速航行、新船和需求减少；查航线距离/吨海里、到港、费率；只有头条没有路线/运费变化，不足确认。S02/S07 |
| 安全事件 → 战险、船员/融资约束 → 拒航或成本转嫁 | CONDITIONAL / ALPHA_INFERENCE | 护航、风险分担、保单差异；查实际承保与改道；保费未变、线路照常则传导可能弱。依据S03安全事件及D的成本暴露，未读取实际保单 |
| 运输/能源成本 → 进口/生产成本 → 消费价格或企业利润变化 | CONDITIONAL | 合约滞后、库存、汇率、替代、利润吸收；看匹配品类进口价/PPI/CPI；若需求降得更多，通胀方向可反转。M01-F；S07/S08 |
| Panama少雨 → 吃水/名额调整 → 限载/排队/改道 | WELL_ESTABLISHED物理约束；经济量化 CONDITIONAL | 节水、降雨、调度、新水源；看正式吃水通知与水位/实际通过量；过去干旱不能证明今天限载。S06/S10 |

**ALPHA_INFERENCE M05-F1：**先区分“货物从出口端出不来”和“只是交付更慢”，再评估能源、库存及运力价格。依据五处路线及S01/S02；替代解释是需求增长或港口罢工驱动运费；若路线正常而港口/需求证据更强，削弱咽喉归因。不是通用事件买卖规则。

**ALPHA_INFERENCE M05-F2：**Suez部分回流与IMO确认袭击可以同时为真；不能用其中一个抹掉另一个。依据S03/S04不同样本/问题；替代解释是仅特定受保护航线回流；只有更广泛船流、船员安全及承保资料才能支持全面恢复结论。

## G. Competing explanations

1. **地缘事件 vs 需求/船队因素。**运价受可用船舶、航速、货量、港口拥堵和合同影响。绕航有明确占船机制，但不能将每次运价变化全归给战争；反向需求冲击尤其重要。[S02/S07]
2. **运河宣传的恢复 vs 全程安全。**SCA报告了实际船舶和累计吨位，但IMO09-16仍报告Hormuz周边及红海袭击。不同地区/期间，既不互相推翻，也不是两个“立场”投票。[S03/S04]
3. **价格水平效应 vs 永久高通胀。**UNCTAD 2024条件模型讨论若特定时期运费增幅持续，则到2025末价格水平较基准高约0.6%；不是已实现的每年通胀增速，也不是2026预测。该正文读取失败，仅索引节选可读，不能升格实证验收。[S08]
4. **船东/保险商一定受益。**提价可能被油耗、战损、赔付、资产闲置与融资成本抵消。无公司账本，本批结论 UNKNOWN，不能转成行业盈利预测。

## H. Current structure

截至本研究日，**2026-09-16 IMO**报告已核验自2026-02-28以来Hormuz及周边80起国际航运袭击，至少22名船员死亡；这支持风险仍存在，不是每起同一归责、整个海峡关闭或今天精确货流。[S03]

SCA **2026-09-16** 披露OOCL PORTUGAL首次通过及截至8月的集装箱船吨位回升，属于部分恢复事实/管理者报告。Panama的2026财年前九个月数据回升，与随后9月预约/吃水限制并不矛盾：观察期不同，水文可以再次变化。S05/S06正文没有可靠显示精确发布日，保留 UNKNOWN；通知生效日期与研究接收日分别保留，不当成今日已执行情况。[S04/S05/S06]

EIA **2026-08-12**文章用季度运输估计，不是网页主导航“9月STEO”所代表的新鲜度。Malacca源内2025Q4冲突未解决。通道地理长期有效，但2023干旱、2024改道和2025恢复均不能直接替代2026日况。[S01/S02]
