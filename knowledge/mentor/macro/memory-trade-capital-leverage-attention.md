最近很多人都在说：“Memory 才是接下来的主线，这次不一样。” 我同意，这次确实不一样。 但我觉得，大部分人还是在用以前的 Memory Cycle 去理解现在这个行情。以前 Memory 怎么崩，很简单：需求起来，价格上涨，厂家扩产，最后供给追上需求，库存增加，价格下跌，整个周期反过来。 所以现在很多人也在等同样的东西：什么时候扩产，什么时候供给追上，什么时候 NAND 或 DRAM 价格见顶。 这些当然都重要，但我不觉得这次最先杀死 Memory Trade 的会是供需。 我更倾向于认为，这一轮最后会先死在资金、杠杆和注意力上。

SNDK 能涨到这么夸张，基本面当然是一部分。AI 对 Memory 的需求是真的，NAND 紧张也是真的。但如果把这种极端涨幅完全解释成基本面，我觉得还是漏掉了市场结构本身。 这里面一个很重要的东西，就是 2X Leveraged ETF。 很多人以为 2X ETF 就是拿到一块钱，然后直接去买两块钱的股票。实际上，很多单股杠杆 ETF 会通过 Total Return Swap 或其他衍生品去获得接近两倍的每日敞口。ETF 本身可以拿着现金或短债，然后由银行提供这个杠杆收益。 问题是，银行不可能裸着这么大的方向风险，所以它也要 Hedge。最直接的方式就是买卖 SNDK 股票，也可以用 Call、Put，或者股票和期权一起做。 所以更准确的说法不是“ETF 在疯狂买 SNDK”，而是 ETF 创造了杠杆敞口，银行和做市商为了管理这个风险，最后会把一部分压力传导到股票和期权市场。 这在上涨的时候会形成正反馈。SNDK 涨了以后，2X ETF 的净资产也涨得更快。为了第二天继续维持大约两倍的敞口，它需要增加更多 Exposure。银行那边的 Hedge 也要跟着加。如果这个 Hedge 最后表现成股票买盘，就会进一步推动 SNDK。 如果期权参与比较多，Delta 和 Gamma Hedge 还会让这个过程更明显。 所以有些股票最后那一段上涨，不一定还能单纯用利润、估值或者 Memory 价格去解释。基本面启动行情，但后面的加速，可能已经有很大一部分来自市场结构本身。 当然，这个机制反过来也一样成立。

一旦 SNDK 开始下跌，2X ETF 的净资产缩小，需要的总敞口也下降。Swap 缩小以后，银行原本的 Hedge 也可以跟着减。如果原来持有的是股票，就会卖股票；如果是期权组合，就会重新调整 Delta。 也就是说，上涨的时候它可以制造更多机械买盘，下跌的时候也可能制造更多机械卖盘。 这也是为什么我觉得，真正的风险不一定从“崩盘”开始。SNDK 甚至只需要先停止一直上涨，就已经会出问题。 Leveraged ETF 最喜欢的是干净的单边趋势。只要开始变成高波动横盘，Volatility Drag 就会出现。股票可能来回震荡，最后还在原地，但 2X ETF 因为每天重新计算敞口，长期表现会越来越差。 这时候 Momentum Trader 也会开始觉得钱没以前那么好赚，Take Profit 会增加，整个交易结构就开始松动。

再往上看，就是 Hyperscaler。 整个 AI Infrastructure Trade 最后真正付钱的，其实就是少数几家公司：Microsoft、Amazon、Google、Meta、Oracle。 Data Center、GPU、Networking、Power、Cooling、Memory，这些东西最后都要靠它们的 Capex 去支撑。 不是说这些公司“没钱了”。这样说太夸张。 更准确地说，是 AI Buildout 的规模已经大到，市场对未来投资的期待越来越难只靠内部现金流轻松支撑，融资的重要性越来越高。 Reuters 今年的报道已经提到，大型 Hyperscaler 正在累积非常庞大的长期租赁、数据中心和债务承诺，而未来几年 AI 相关融资需求还在继续上升。这里真正危险的地方，不是这些公司会破产，而是它们越来越依赖一个持续便宜、持续宽松的资本环境。 所以利率就变得非常重要。 如果钱便宜，这套东西可以一直往前滚。融资成本低，Data Center 好建，股票估值也容易维持，企业愿意继续借钱，市场也愿意给高 Multiple。 但如果利率往上走，问题会同时出现在两边。 一边是 Hyperscaler 的融资成本变高。对于几十亿、几百亿甚至更大的基础设施项目，利率高一点就是非常大的差别。 另一边是股票估值被压。利率越高，未来利润折现回来的价值越低，同时 Treasury 本身也更有吸引力，投资者就更难接受极高的成长股估值。 所以高利率一方面打击 AI Infrastructure 的融资能力，另一方面压缩 AI 相关股票的估值。 这也是为什么 Trump 一直希望利率往下走。不能简单说他的目的就是“救股市”，但低利率对股市、企业融资和 AI Capex 都明显更友好，这一点没有争议。 问题是，如果市场没有得到更便宜的钱，反而继续得到更贵的钱，那整个 AI—Hyperscaler—Memory 这条链条都会慢慢承压。 而且股票不需要等到实际需求开始下降才跌。

Hyperscaler 可能只是把一些项目推迟三个月，少建几个 Data Center，或者把 Capex Growth 从 50%降到 20%。 Memory Demand 可能还是增长的。 但股票已经会先跌。 因为市场交易的从来不是“需求有没有增长”，而是“有没有比预期更好”。 这才是我觉得这轮 Memory Cycle 最不一样的地方。 以前大家等的是 Supply Catch Up。 这一次，我觉得更应该看 Attention。 这一轮 AI Trade 一路是这样走过来的：NVDA、Semiconductor、Data Center、Power、Nuclear、Networking、Cooling，然后现在轮到 Memory。 市场一直在找“下一个还没涨够的 AI Trade”。 Memory 不是突然变重要了，它一直都重要。只是现在资金和注意力刚好轮到这里。 但注意力是会走的。 当所有人都已经知道 AI 需要 Memory、Memory 紧张、价格上涨、Hyperscaler 还在继续投资，这些东西就不再是新的信息。 一旦市场开始找下一个故事，可能是 Robotics，可能是 Defense，可能是 Biotech，也可能是 Commodities，具体是什么不重要。 重要的是钱开始往别的地方走。 所以我为什么觉得明年年中左右，Memory Trade 很可能开始退潮？ 不是因为我确定那个时候 NAND 会过剩，也不是因为我认为 AI Demand 会突然消失。 我的判断只是，到那个时间附近，这个 Narrative 很可能已经没有今天这么新鲜了。 Memory 的实际业务可以还很好，价格可以还很高，AI Demand 可以还很强，但股票一样可以跌。 因为股票最后交易的，不只是公司本身。 它交易的是有没有下一批人愿意用更高的价格接手。 当新买家开始减少，Momentum 变弱，Leveraged ETF 不再提供同样的助力，波动增加，资金开始撤出，整个结构就会反过来。 到时候很多人可能会问： “Memory 明明还是缺货，为什么股票跌了这么多？” 答案可能很简单。 不是 Memory 先变了。 是市场先不想继续买这个故事了。 这就是我觉得这一次真正不同的地方。 以前很多 Memory Cycle 是基本面先坏，股票再坏。 这一次，完全可能是股票先坏，资金先走，Narrative 先结束。 然后很久以后，供需才真的发生变化。
