Mechanical Stop Loss｜机械止损

机械止损就是给股票设一个固定的最大亏损线。对我来说，一般是 -7%。

如果一只股票从我的入场价跌了 7%，通常说明至少有一件事错了：我的入场时机不对。 与其继续扛，我更愿意先止损，重新观察，等更好的机会再进。

为什么是 7%？没有什么神奇的数学公式。对我来说，它是一个心理上容易接受的损失数字。即使止损后股票马上反弹、甚至因此错过行情，我也能接受。交易最重要的是控制单次错误的代价，而不是抓住每一次行情。

机械止损更适合股票，不适合直接套用在期权上。 期权价格受到波动率、Theta、到期时间、Delta 等多种因素影响，短时间出现 20%、30% 甚至更大的价格波动并不罕见。简单用「亏 7% 就砍」往往没有实际意义。

核心：股票跌 7% → 承认入场可能错了 → 先退出 → 等待重新入场。

Positional Stop Loss｜仓位止损

仓位止损适用于：我仍然相信这笔交易最终可能会走对，但短期的下行风险正在增加。

这时候我不会像机械止损一样全部退出，而是主动降低仓位，把风险控制到即使继续下跌，也不会造成重大损失的程度。

这样做的代价是：如果判断正确，利润会减少。但我保留了资金和主动权。

如果价格开始反转，并重新证明我的原始判断是对的，我会愿意追涨重新加仓。我宁愿用更高的价格买回确定性，也不愿为了一个更好的成本价承担过大的下行风险。

核心：还有信心，但风险增加 → 减仓降低暴露 → 等市场确认 → 反转后重新追入。

Thesis Stop Loss｜逻辑止损 你买入一只股票，是因为你有一个明确的投资逻辑（Thesis）。 比如： 

- 政府收购
- 战争即将爆发
- 新 CEO 上任
- 药物试验前景很好
- 重磅产品即将发布

 无论是什么，它给了你一个理由相信：这家公司存在值得下注的叙事或基本面价值。 Thesis Stop Loss 不看你亏了多少，而是看当初买入的理由还在不在。 一旦事实证明这个逻辑已经失效，立即退出。 核心：因为一个理由买入 → 理由还在就继续观察 → 理由消失就走。不要为了仓位重新编一个理由。

Technical Stop Loss｜技术止损 技术止损是指：技术面已经告诉你，这个仓位继续持有的理由正在消失，因此需要减仓或完全退出。 常见信号包括： 

- 跌破关键支撑位
- MACD 进入下降趋势
- RSI 持续走弱
- 布林带呈下降趋势
- 跌破或转弱于 50 / 200 日均线
- Vortex Indicator 显示下降趋势
- 下方存在即将回补的缺口（Gap Fill）

 单个指标未必代表必须止损，但当多个技术信号同时恶化时，你需要承认：当前价格走势已经不再支持你的仓位。 这时不要跟图表争论。根据风险程度减仓或退出，保护本金。 核心：技术结构破坏 → 风险上升 → 减仓或退出 → 等技术面重新确认后再进。

Time-Based Stop Loss｜时间止损 时间止损不是因为价格跌了多少，而是因为：这笔交易在预期的时间内没有发生。 你进入一笔交易时，通常不仅有方向判断，也应该有一个大概的时间预期。 例如： 

- 财报后应该快速突破
- 某个催化剂应该在几天内发生
- 突破后应该迅速出现跟进买盘
- 事件驱动交易应该在事件前后兑现
- 短线交易却连续几天横盘不动

 如果时间不断过去，而预期中的行情始终没有出现，就应该考虑减仓或退出。 这在期权交易中尤其重要，因为即使方向最终正确，Theta、IV变化和到期日也可能让你输钱。 除了时间止损，也可以在建仓时使用内置止损结构，例如借方价差（Debit Spread）。通过同时买入一个期权、卖出另一个期权，可以预先限定最大亏损。通常，最大亏损就是建立价差时支付的净权利金，而不是无限扩大。 对于组合期权交易，必须在下单前明确计算： 

- 最大亏损是多少
- 最大盈利是多少
- 盈亏平衡点在哪里
- 哪些价格和时间条件会导致最大亏损
- 到期前是否需要主动平仓或调整

 例如，买入看涨期权并卖出更高执行价的看涨期权，构成看涨借方价差。其最大亏损通常等于净借方，最大盈利则是执行价差减去净借方。这样，交易者不需要依赖盘中情绪或临时设置止损，也能在建仓时知道最坏结果。 但需要注意，借方价差并不等于没有风险。价差仍然会受到标的价格、Theta、隐含波动率、流动性和到期时间的影响。若组合中包含多个期权，也应先理解整个组合的风险，而不是只看单个期权的盈亏。 核心：方向可能没错，但时间不等人 → 行情迟迟不兑现 → 通过时间止损减仓或退出；同时，优先使用能够明确最大亏损的期权结构 → 在建仓前理解组合的最大风险 → 把资金留给更有效率的机会。

Built-In Stop Loss｜内置止损 内置止损是通过期权组合本身的结构，在建仓时就把最大风险限制住。 与其买入或卖出单腿期权承担较大的风险，可以使用 Spreads（价差） 或其他期权组合，让另一条腿成为仓位自带的保护。 例如： 

- Call Debit Spread｜看涨借方价差
- Put Debit Spread｜看跌借方价差
- Call Credit Spread｜看涨信用价差
- Put Credit Spread｜看跌信用价差
- Iron Condor｜铁鹰
- 其他 Defined-Risk Option Structures｜有限风险期权组合

 例如你看涨一只股票，与其单独买 Call，可以买一个 Call，同时卖出更高执行价的 Call。 你牺牲了一部分潜在利润，但同时： 

- 降低建仓成本
- 限制最大亏损
- 减少部分 Theta / IV 风险
- 在下单之前就知道最坏情况

 对于卖方策略尤其重要。裸卖期权可能存在非常巨大的风险，而加入保护腿以后，可以把原本难以控制的风险变成一个预先计算好的最大亏损。 内置止损的核心不是「亏了以后怎么办」，而是： 在交易开始之前，就决定最坏情况下你愿意亏多少钱。 核心：不要等风险出现以后才想止损 → 用期权组合提前定义风险 → 牺牲部分收益换取可控的最大亏损。

Volatility Stop Loss｜波动率止损 波动率止损是指：价格方向可能没有完全错，但波动率环境已经发生变化，使原来的交易不再划算。 期权价格不仅取决于股票涨跌，也受到 IV（隐含波动率） 的影响。 常见情况： 

- 财报后出现 IV Crush（波动率坍塌）
- 买入期权后 IV 大幅下降
- 卖出期权后 IV 突然飙升
- VIX / 市场整体波动率环境发生剧烈变化
- 原本预期的大行情迟迟没有出现，波动率开始消失
- 期权价格与标的走势之间的关系已经不再有利

 例如，你买 Call 看涨，股票甚至可能真的上涨，但如果 IV 大幅下降，期权仍然可能亏钱。 反过来，你卖出期权赚 Theta，但如果市场突然进入高波动环境，IV 暴涨也可能让仓位迅速产生巨大浮亏。 因此止损不能只看股价方向，还要看你当初下注的波动率逻辑是否还成立。 核心：方向没有错 ≠ 期权交易没有错 → 波动率环境改变 → 原来的风险收益比消失 → 减仓、调整结构或退出。

Overnight Stop Loss｜隔夜止损 隔夜止损是为了保护自己免受市场收盘后的突发风险。 普通 Stop Loss 有一个很大的问题： 市场关闭以后，你无法保证在哪里成交。 例如： 股票 $100 收盘，你的止损是 $95。 如果晚上突然出现重大利空，第二天股票直接 $80 开盘，你的止损并不能保证你在 $95 卖掉。你可能只能在 $80 附近退出。 所以： Stop Price ≠ Guaranteed Exit Price 什么会造成隔夜风险？ 

- 财报
- 公司重大公告
- FDA / 临床试验结果
- 战争和地缘政治事件
- 政府政策变化
- 利率、汇率和商品价格变化
- 海外市场突然暴跌
- 第二天盘前的重要经济数据

 这些事情发生的时候，你可能根本没有机会及时退出。 怎么做隔夜止损？ 真正的隔夜止损应该在收盘之前完成。 如果隔夜风险太高，可以： 

- 减少仓位
- 直接平仓
- Long Position 买 Put
- Short Position 买 Call
- 用 Spread 限制最大亏损
- 用 SPY / QQQ 等对冲组合风险
- 降低杠杆

 你白天愿意持有的仓位，不代表晚上也必须全部留下。 Daytime Size ≠ Overnight Size 尤其是期权，隔夜还要考虑 Gap、IV、Theta、Gamma。重大事件前，更应该控制仓位或者使用 Defined-Risk Structure。 隔夜止损的目的不是预测明天涨还是跌。 而是问自己一个问题： 如果明天出现最坏的情况，我能不能承受？ 如果不能，就应该在今天收盘以前降低风险。 核心 市场即将关闭 → 判断隔夜风险 → 风险太高就减仓、平仓或对冲 → 只留下自己能够承受的仓位。 隔夜止损不是明天开盘再止损，而是今天收盘前决定你愿意带多少风险过夜。

Hedging Stop Loss｜对冲止损 对冲止损不是直接卖掉原来的仓位，而是建立一个反方向的仓位来限制损失。 适用于：你仍然相信原来的投资逻辑，但短期出现了无法忽视的风险，又不希望完全退出。 例如：

- 持有大量股票 → 买 Put 保护下跌
- 持有大量科技股 → 买 QQQ / SPY Put 对冲市场风险
- 做多某个行业 → 做空相关 ETF 降低行业风险
- 持有 Call → 卖出更高执行价 Call，变成 Spread
- 卖 Put → 买更低执行价 Put，限制最大亏损
- 持有隔夜仓位 → 用指数期权保护突发风险

 对冲通常需要付出成本，也可能降低你的潜在利润。 但它的目的不是赚钱，而是让你在判断暂时错误的时候仍然能够留在牌桌上。 你不一定需要对冲掉 100% 的风险。根据情况，可以只对冲一部分仓位，在保留上涨空间的同时降低下行暴露。 核心：仍然相信原仓位 → 短期风险增加 → 不想完全退出 → 建立反向仓位降低风险 → 风险消失后解除对冲。 [旧频道迁移内容] 原发于 2026-08-30 12:31 JST

1. Cost Control｜成本控制 成本控制是指：在进入交易之前，通过控制你的入场价格、仓位大小和期权成本，提前降低未来止损的压力。 很多亏损不是因为方向判断完全错误，而是因为： 买得太贵、仓位太大、追得太急。 例如：
   - 股票已经暴涨后不要盲目追高
   - 等待回调到更合理的位置再入场
   - 分批建仓，而不是一次投入全部资金
   - IV 极高时谨慎买入期权
   - 不要为短期期权支付过高的 Premium
   - 使用 Limit Order 控制成交价格
   - 用 Spread 降低期权成本
   - 如果找不到合理的入场价格，宁愿错过交易
    假设你认为一只股票合理的止损位置是 $90。 在 $100 买入，你承担约 10% 的风险。 如果耐心等到 $95 才买入，同样的 $90 止损，你承担的风险就明显降低。 好的成本本身就是一种风险控制。 不要因为害怕错过行情，就把自己逼进一个风险收益比很差的位置。 核心：风险控制从买入那一刻就开始 → 控制成本 + 控制仓位 + 拒绝追高 → 给自己留下更大的容错空间。


Fighting Against Stop Hunting｜应对止损猎杀 止损猎杀（Stop Hunting）是指价格短暂刺穿明显的止损区域，触发集中止损单后迅速反弹或回落。它可能来自流动性搜寻、机构订单执行、市场波动或其他交易者对常见止损位置的预判。 普通止损单最大的弱点是：它无法保证你的成交价格，也无法避免被短暂波动触发。 例如股票交易在 $100 附近，你把止损设置在 $95，而市场普遍关注 $95 这一整数位或前低。价格可能先快速下探至 $94.80，触发止损后又反弹至 $100。你已经在低位退出，却错过了后续反弹。 因此，防范止损猎杀不能只依赖“把止损放得更远”，而应结合市场结构、仓位和执行方式。 常见方法： 

- 不要把止损直接放在明显的整数位、前高前低或趋势线外侧
- 根据波动率和市场结构设置止损，而不是使用固定百分比
- 避免把止损放在过于拥挤、容易被识别的区域
- 先确定最大可接受亏损，再通过调整仓位来给交易留出合理波动空间
- 等待价格收盘确认或结构破坏后再退出，避免被单次影线扫出
- 使用分批止损、分批减仓，降低一次性被触发的影响
- 在流动性较差、开盘或重大数据公布时段减少仓位
- 使用期权保护或价差策略限制最大亏损，但要充分考虑流动性和成本
- 不要为了避免止损猎杀而无限扩大止损距离；如果风险超出计划，应直接放弃交易

 需要注意的是，并非每次止损触发后反弹都是止损猎杀。很多时候，止损被触发说明原有交易逻辑已经失效。判断关键在于：价格是否只是短暂刺穿关键位置后迅速收回，还是已经形成有效突破并持续运行。 核心：不要试图预测或完全避免止损猎杀 → 根据市场结构和波动率设置合理止损 → 通过控制仓位管理风险 → 只有在交易逻辑仍然成立时，才考虑等待确认或分批退出。

30/30 Rule｜30/30法则

这是我个人用于期权止损的一条简单规则。

当一笔期权交易的 Thesis（交易逻辑）开始失效时，我给自己两个限制：

30% 时间 / 30% 亏损

哪个先到，就必须认真考虑退出。

30% 时间：
从交易逻辑开始出现问题算起，如果已经消耗了期权剩余时间的约 30%，而行情仍然没有重新证明我的判断，就退出。

30% 亏损：
如果期权价值已经亏损约 30%，即使还有很多时间，也不继续无限等待。

例如，一个期权还剩 30 天，而 Thesis 开始出现问题。我最多再给它大约 9 天去证明自己。

但如果第二天期权已经亏损 30%，就没有必要等完这 9 天。

这条规则的目的不是证明 30% 是一个神奇的数字，而是防止自己在 Thesis 已经破坏以后，因为“还有时间”或者“不想认亏”而一直拖下去。

核心：Thesis 出现问题 → 30% 剩余时间或 30% 期权亏损 → 哪个先到，就退出。

Re-Entering & Adding｜重新入场与加仓

我的原则很简单：

不追亏损，只追盈利。

对于正在亏损的仓位，我最多允许自己进行 一次高度纪律性的加仓。这次加仓必须有明确理由，例如更好的成本、关键支撑位，或者原来的 Thesis 仍然成立。

如果加仓以后继续错，我不会不断补仓摊低成本。

因为不断给亏损仓位加钱，很容易把一个小错误变成大错误。

但对于正在盈利、而且市场不断证明我的判断正确的仓位，我允许自己追涨和继续加仓。

即使新的买入价格更高也没有关系。市场正在证明我的 Thesis，而不是否定它。

核心：亏损仓位最多一次纪律性加仓 → 越错越减少风险；盈利仓位可以追涨加仓 → 越对越增加风险敞口。

不要用更多的钱证明自己没有错。把更多的钱放在市场已经证明你是对的地方。
