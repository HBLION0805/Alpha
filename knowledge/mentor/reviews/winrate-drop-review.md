# 大佬交易复盘：胜率从85%掉到20%（原文，已去名字时间）

这几天，我重新看了过去一周的每一笔交易，一直在问自己：为什么我的胜率会从85%以上，掉到这周大约20%？ 仓位控制让亏损保持在可控范围内，我预计最终仍能盈利。但这不能成为交易做得不够好的借口。我能不能选出更好的交易、把仓位管理得更好？当然能。 过去两周，我对自己有了更多认识。我需要少花一点时间安抚情绪、解释和捍卫每一个操作，多花一点时间研究市场。在遵守逻辑失效条件的前提下，也要给自己的判断足够的时间兑现。 我可以把压力归咎于别人，但打破规则的人是我自己。为了满足一些人想看交易、想找刺激的需求，我做了不必要的单子；原本同时管理不到10个仓位，后来膨胀到接近30个；我过于在意避免小亏，反而在交易逻辑还没来得及兑现之前，就提前离场。 这些都是我自己的决定。改正，也是我的责任。 接下来，我会做出以下调整：

1. 周一不再参与群聊。 给自己留一点休息和思考的时间。我仍会在周一收盘前一小时看看有没有值得做的机会，但不会为了有东西跟大家分享而硬做交易。

2. 把同时管理的仓位降回10个以下，不再为了教学或满足刺激需求而开单。 每一个仓位都必须有值得持有的理由。教学应该是解释我的交易体系，而不是为了满足观众去改变这套体系。

3. 更多依靠社区共同维护好的交易习惯。 请读日报、观察市场、理解交易逻辑。关于风险、仓位管理，以及什么情况下逻辑失效的问题，欢迎讨论。但同样五个问题反复回答20遍，只为了让人暂时安心，并不能帮助任何人成为独立的交易者。交易中正常的不适，需要我们每个人学会自己消化。

4. 不再把自己的烂交易归咎于任何人。 我的判断、执行和离场，都应该由我自己负责。把责任推给经验远不如自己的人，不是领导力，也不是担当，是懦弱。

我会做得更好。我会用更高的标准要求自己，给大家更清晰的逻辑、更有纪律的执行，也会他妈的更加认真地教。 你们的交易结果，最终仍取决于你们自己的决定。我的责任，是让教给你们的东西值得学，也让自己先做到。 爱你们。愿上帝保佑大家。一起赚钱。
