## Outcome audit design

New deterministic composition accepts existing paper scenarios and original
historical run envelopes. Recompute both existing engines; never accept a caller
assertion of a profitable result. The local CLI obtains these inputs through
existing repository readers inside their locks and compares bytes before/after.
Missing/busy/unsafe/corrupt stores remain independently visible. No source store
or trade is added by audit commands. Future scenario clocks remain hypothetical;
they cannot become actual historical research or brokerage execution clocks.

Report exact integer cents, bounded counts and declared truncated integer ratios.
Closed-case mean net PnL is a numerator/denominator pair. Profit factor is null
when there are no losing cases, never infinity. Realized drawdown is defined only
for the shared paper account's chronological closed outcomes, excludes open
marks and does not represent the independent historical trials. No aggregate
historical equity curve or cross-run compounding is allowed. Every case retains
its source identity, status, blocker codes and review references. Candidate lesson
counts and reported process violations remain distinct from causal conclusions.
