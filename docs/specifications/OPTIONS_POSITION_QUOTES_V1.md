# Targeted position quote review V1

Owner-initiated, local-ledger single-leg GLD/IBIT review. Prepare an immutable
request in Position exit checks or CLI, execute the exported collector inside the
existing authorized Host, record the returned receipts, then read the existing
page. Preparation and page refresh never call market tools. No queue or timer.

Only open reported quantities are selected. Verified saved capture metadata
supplies complete contract identity and historical chain provenance. Ambiguous
identity remains uncovered. More than six distinct contracts requires an explicit
trade subset; all excluded trades remain visible. Synthetic ledgers cannot issue
a production Host permit. Tests inject tools in isolated workspaces only.

One exclusive existing Host slot permits at most two calls, one ETF batch and one
option-ID batch (at most six IDs). This is below the existing 24-call/36-quote
capture ceilings, not a new daily quota. The scheduled 15:50 window is reserved
for routine collection. No retry after failure or repeated claim. Actual-time
regular-session calendar gates and a three-minute request-start bound apply.
Per-request guards recheck the ledger and permit before each tool invocation.

Bounded, fingerprinted request / claim / result records use existing safe local
storage. Raw receipts are retained once in the result. Targeted frames never enter
the guidance or research capture catalog. Existing exact price, session, quote,
fees, stop, target, time and thesis evaluators remain authoritative. Quotes failing
identity or clock checks cannot fall back to favorable older quotes. Persisted
exit triggers survive later missing/stale quotes. Ledger changes during a read
are retained as a binding failure; no old position conclusion is made current.

The page distinguishes saved evaluation time from current evidence age and lists
coverage, missing identities, calls, returned rows, writes and UNKNOWN dollar
cost. A review is not a fill, continuous monitor, source qualification or an
authorization to exit automatically. First live use and routine natural
collection acceptance remain separate from isolated functional verification.
