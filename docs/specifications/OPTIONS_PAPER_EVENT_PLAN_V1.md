# Event-linked paper planning V1

September 12, 2026. F03–F05 integration. The selected option already has exact
paper economics and entry/exit clocks, but its event hypothesis and original
recommendation evidence are not retained with the paper registration.

## Reviewed design

Extend the existing paper registration with an opt-in V2 envelope carrying a
versioned event context. Keep the underlying paper plan V1/V2, fills, costs,
qualification and all old registration/report fingerprints unchanged when absent.
The new registration copies and independently recomputes the original issued
guidance bytes, including its assessment/source clocks, candidate blockers and
calendar. It binds the selected contract and capture to that issued evidence.
Do not use today's sources to explain a previously frozen plan.

The Owner can choose PRE_EVENT or POST_EVENT and enter an original hypothesis,
entry confirmation and invalidation. These bounded English declarations are
qualitative research notes, never verified observations or automated triggers.
The new event registration must be prospective. Its existing same-session paper
entry start, deadline and time exit remain explicit, before expiry and within the
reviewed session model. PRE_EVENT must close strictly before the event; date-only
events use the earliest named New York date conservatively. POST_EVENT requires
a timed calendar entry and an entry start strictly more than 30 minutes after it,
matching the existing stabilization boundary. Never invent a FOMC release time.
The plan cannot silently cross another known major event. All-time coverage stays
limited to the copied official-calendar subset, not a guarantee of no other news.

Frozen context displays event, phase, exact contract, windows, original guidance
decision/blockers, source dates, entry condition, invalidation, and unchanged
premium stop/net-R assumptions. Preview and recovery use the same assessment.
Optional attachment does not clear WATCH or qualify a trade. The quote-only paper
model does not evaluate prose, order flow, OHLCV confirmation or event causality;
label hypothesis validation NOT_TESTED on every result, including profitable runs.
Carry that limitation into the existing candidate mistake notebook. No approved
rule or causal explanation is derived from a modeled win.
Timing checks enforce coherence only. Real Owner decisions remain manual.

Reuse the existing protected preview/freeze routes, immutable storage and local
paper frontend. No new source reads, enrollment, scheduler changes or orders.
UI keeps edited drafts and invalidates previews when any field changes. Frozen
registrations and saved reviews expose the copied context after restart and in
isolated recovery. No production plan is registered or enrolled by this delivery.

## Acceptance

PRE/POST time boundaries, date-only event handling, other event crossings, absent
or duplicate event keys, copied-report tampering/recomputation, contract/capture
binding, prospective clocks, unknown costs and allocation preservation. Verify
old behavior byte-for-byte, explicit new idempotence/conflicts, recovery without
source stores, escaping, preview invalidation, current live UI with no writes,
and an isolated synthetic linked-plan lifecycle retaining NOT_TESTED.
