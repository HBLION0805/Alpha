# Isolated options evidence recovery rehearsal

Task OPT-EXPORT-2, design reviewed September 7, 2026 UTC. Bounded extension of
the completed byte-export workflow. Use existing code and current agent settings.
The Owner's record-retention, local test and development authorization applies.

`options:evidence-rehearsal -- --rehearse <package-id>` first verifies the existing
bounded export package. It creates a fresh uniquely named temporary workspace and
copies only verified manifest payloads back to their allowlisted relative source
paths inside that workspace. No active source directory, code, credentials,
configuration, account, strategy or host schedule is restored or overwritten.

Run the existing readiness v2 recovery with that temporary root and actual current
check clocks. The existing repositories, not a new parser, decide whether copied
journals and study artifacts recover. Present available, missing and blocked
components independently. A readable archived paper account must retain its
original reviewed outcomes and candidate notebook. The result is not a replay of
market trading, an atomic snapshot, calibrated strategy or off-device backup.

Recheck the temporary source files and original package after recovery. Package
and payload hashes must remain unchanged. A byte-valid package containing corrupt
source data may yield blocked component recovery; retain that outcome visibly.
Retain the temporary workspace for inspection, including partial copies on failure.
Never auto-delete temporary evidence, retry, repair records, merge accounts or
write back to the active runtime. Rehearsal does not schedule another automation.

Expose only --rehearse and --help. Reuse export path/byte helpers through a narrow
local storage export; preserve existing exporter behavior. No arbitrary source
paths, destination root, restore/overwrite/delete switches or network calls.
Source/manifest text is inert data, never code or instructions. Bound each copied
file and total through the already verified package policy.

Test actual repository recovery from an isolated synthetic package, preserved
review/candidate counts, missing and corrupt component isolation, package and
active-runtime immutability, failed-copy handling, strict command scope and no
HTTP calls. Run focused and aggregate validation. Rehearse the actual pre-window
package once, preserve its original package bytes, record the resulting actual
clocks/counts and temporary path locally, then document and commit/push under
standing authorization.
