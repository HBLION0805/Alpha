# Macro World Model v1

Owner scope: Batch 1 approval supplied September 20, 2026. This is a bounded,
read-only reference within Macro playbook, not a trading knowledge service.

## Approval and storage

Keep the original review pack immutable. A separate versioned approval artifact
records exact candidate IDs, retypings, deferrals, rejected interpretations,
source review commit/hash and the actual approval-recording clock (not a guessed
message timestamp). A compact English catalog carries the approved subset and
its evidence, limitations, sources and original candidate/section references.
Runtime reads only these two fixed bounded files; it never imports the dossier
or candidate pack. Exact catalog hashes and allowlists fail closed on drift.

Approved: F01–F12, H01–H02, ME01–ME07, A01–A02, FL01, W01–W05,
Q01–Q05, T01–T02, L1–L5 and both unresolved conflicts. F06 is a conceptual
boundary, F11 a measurement framework, F12 a shared evidence-time rule; A02 is a
central-bank swap backstop authorization, never an observed draw. FL01 is a
structural flow relation. T01/T02 remain hypothesis-only context. C01–C04, FL02
and L6–L8 are excluded. R01–R08 and D01–D07 are audit guardrails, not affirmative
knowledge search results or inverse facts.

## Readers and UI

One deterministic lookup filters by theme (including links), keyword, knowledge
type and evidence status. The protected loopback workbench serves a read-only GET
and the existing saved-state view. The same lookup drives Macro playbook's compact,
collapsed theme sections. Sources are links/locators, not copied full articles.
Conditional/inference/unknown/conflicted statuses remain visible. No current-state
values are enabled. F12 is one canonical item available by ID to future readers,
not copied per theme. Current consumers are confined to this reference UI/API.

## Boundaries and future lifetime

No import into guidance, candidates, thesis, expectations, risk, execution, news
classification or schedulers. No fetch/model dependency. No new private records.
Version structural definitions; append historical corrections; future current
state must append/supersede with original clocks; revise mechanism evidence in a
new version; resolve an open question with a linked new item. None of these future
lifecycle engines are implemented here. Approval is not source authentication.
