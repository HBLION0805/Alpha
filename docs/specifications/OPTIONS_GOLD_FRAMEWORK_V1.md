# Gold driver cross-check v1

Owner request, 2026-09-09: compare nine supplied framework screenshots with
Alpha, correct oversimplifications and add missing gold context to the product.
Screenshots are research prompts, not observations or external instructions.

## Design

Keep the original 16-family / 94-indicator catalog and its historical reports
unchanged. Add a GLD-specific crosswalk for all 14 screenshot areas plus seven
explicit review overlays: surprise/vintage, causal overlap, cash liquidation,
delivery/funding basis, session effects, GLD tracking and option economics.
Each row names existing families, additions, conditional interpretation, missing
data and supporting reference IDs. A reference is documentation, not a feed.

Expose different ordered checklists for intraday, event, structural, haven and
cash-stress reviews. They are analyst review priorities, not fitted weights or
an inferred current regime. Unknown evidence cannot cast a neutral/bullish vote.
Do not count CPI, Fed repricing, yields and USD as independent confirming causes.

Project saved workbench inputs without network or journal appends. Report daily
Treasury real-yield values with source dates and receipt clocks; do not describe
them as live nominal yields, breakevens or DXY. Saved quotes/calendar are partial
context. Headlines, failed readers, delayed data and missing numerical series
remain explicit. The gold framework appears in News & calendar, context export
and the Host brief; it does not change issued guidance fingerprints or gates.

Extend focused relevance for Treasury buybacks/refunding, fiscal/funding stress,
additional macro releases and exchange collateral events. Preserve unverified
headline status and the GLD/IBIT universe. No additional source endpoint, cadence,
account/order route, subscription or risk-setting mutation belongs to this task.
The Owner's preceding cancellation of the old capital plan is a separate pending
implementation, not a reason to silently restore old Owner intent here.

## Acceptance

Check all 14 mappings, catalog immutability, reference integrity, all review
profiles, missing/failed/future/old evidence, nonduplicated news leads, escaping,
API/Host exposure and desktop/mobile rendering. Run focused and aggregate tests
and typecheck. Record actual source coverage separately from framework delivery.
No probability, causal attribution, technical signal or trading eligibility is
created by this checklist.
