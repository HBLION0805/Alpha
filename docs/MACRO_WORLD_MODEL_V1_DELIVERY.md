## Implementation and boundaries

Two bounded application JSON files are read and hash-checked. Approval drift,
unapproved IDs, semantic type/grade mismatch or broken mandatory references fail
closed. Scoped LF attributes preserve pinned bytes on Windows checkouts. There is
no fallback to dossier prose. Original education notes still copy only their old
playbook catalog. Trade projections never read the new component; the component
is appended after existing projections. No account, market, model or news adapter
is involved. No new mutation endpoint, record store, dependencies or scheduler.

Files: the two JSON artifacts; the bounded reader; two frontend lookup/render
files; minimal workbench asset/GET/state/playbook/filter/style connections; focused
tests and inclusion in the existing full validation; scoped Git attributes; this
delivery, [specification](specifications/MACRO_WORLD_MODEL_V1.md), architecture,
decisions and changelog. No changes to risk, allocation, expectations, event mode,
guidance engine, candidate engine, position checks or frozen studies.
