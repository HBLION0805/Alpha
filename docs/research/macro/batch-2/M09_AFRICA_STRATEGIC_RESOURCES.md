# M09 — Africa and Strategic Resources

研究日期2026-09-20（America/New_York），Codex/Alpha研究与同人自审。案例选择按可取得的矿山、股权、融资与运输证据，不代表整个非洲。禁止runtime使用，不进入Review Gate。

## A. Executive definition

资源影响力分散在矿权、开采、加工、出口许可、铁路港口、电力、融资及市场准入。拥有矿山股份并不等于拥有地下全部资源、控制所有精炼能力或取得当地政治支配权。Owner 的资源 → 基建 → 融资 → 政治 → 安全链条前几段可逐项研究，后几段不能由同期事件直接推断。

选择三组可比较案例：**DRC TFM/KFM铜钴**（矿山产量与出口条件），**赞比亚Mopani与Angola/DRC Lobito**（股权融资及运输路由，二者不是已证明相连的同一货流），**尼日尔SOMAÏR铀**（经营控制、法律争议和外交合作）。未覆盖的锂、稀土、油气国家不作外推。[S01–S11]

## F. Causal mechanisms

1. **SUPPORTED_MECHANISM：资源 → 商业基础设施。** 货量可支撑铁路/港口融资与单位运费改善；只有连接、运营可靠性和通关实际完成，才产生交付收益。S06证明一条路线发生过运输，S11同时列出尚处研究/建设的其他段，不能拼成全线现成能力。
2. **CONDITIONAL_HYPOTHESIS：矿山增产 → 可交易供给。** 需出口许可、运输、买家加工和库存释放。钴出口限制、品位、回收率或缺电都可使矿山产量不等于终端供应。[S01/S07]
3. **ALPHA_INFERENCE：融资/长期承购 → 谈判依赖。** 还款、替代买家、货币和合同决定依赖方向；不是出资即可政治控制。本批没有秘密交换或安全承诺证据。
4. **DISPUTED：政权/安全变化由矿产争夺导致。** 尼日尔国有化与俄尼MOU有时间顺序，但不足以识别政变原因或证明铀被俄方接收。替代解释包括国内权力、税收/经营争议和外交关系变化；每种都需独立证据。[S08/S09/S10]

## H. Current structure

近期可核的2025实绩来自2026公司披露；当前网页上的矿山能力是公司口径，不是独立工程验收。[S01/S02] Lobito融资页与EU合作页证实项目仍有多种融资/建设层级；没有2026全走廊运营验收和提款对账，不能声称已完成。[S05/S11]

Orano2025年报与尼日尔2025声明对合法性、补偿有分歧：政府描述补偿原则，公司称未获补偿。两者可能涉及“应付”和“已付”不同问题，不能简单平均。当前法律终局、实物控制及出口结算仍待合同/裁决/运营资料。[S08/S09]
