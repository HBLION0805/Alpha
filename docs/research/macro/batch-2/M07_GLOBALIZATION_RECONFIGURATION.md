# M07 — Deglobalization / Globalization Reconfiguration

研究日期：2026-09-20（America/New_York）；Codex/Alpha研究与同人自审，非独立审核。禁止 runtime 使用。阅读日期不能替代统计期或预测发布日期。沿用 [Batch 1](../batch-1/BATCH_1_SYNTHESIS.md) 的来源/反证方法。

## A. Executive definition

“去全球化”必须先说明测量对象：全球贸易相对产出持续缩小、特定双边贸易减少、跨境生产被本地产出替代、金融投资撤离，还是战略产品重新分组。它们可以同时发生，也可能相反。关税新闻增多不能直接证明全球跨境交换总量下降。

Owner 的效率 → 依赖 → 安全/韧性 → 政策 → 重配链条有机制依据；但不是各国一致行动的必然历史规律。OECD研究提醒，全面本地化本身也可能削弱韧性；IMF对“连接国”的不同实证研究表明，换一条贸易路线并不必然降低最终上游依赖。[S04/S05/S06]

## C. Actors

贸易/财政/安全部门、企业采购和投资委员会、生产国与消费国劳动者、港口物流与贸易金融机构、多边组织、第三国加工商、资源出口国。国内生产者可能受益于保护，使用进口中间品的下游却承担成本；同一政府的安全目标和消费者价格目标也可能冲突。

## E. Flows

| 对象/分类 | 应读什么 | 不能据此声称什么 |
|---|---|---|
| 商品/服务 EXPORT_FLOW | 实际数量、价格、目的地、增加值来源 | 美元金额下降未必货量下降；服务贸易不能与货物吨数相加 |
| Trade/GDP 比率 | WDI定义为货物与服务进出口之和/GDP [S03] | 含跨境中间品重复跨越；不是“GDP中来自外国的净增加值份额” |
| FDI FLOW / STOCK | 资本流入、再投资收益、股权/关联债、存量估值分别看 | FDI名义存量变动可能有VALUATION_CHANGE；不全是新工厂现金 |
| Greenfield ANNOUNCEMENT | 拟投资金额、项目数量及计划地址 | 宣布数不等于CAPITAL_DISBURSEMENT、投产或就业 |
| 国内 PRODUCTION_CAPACITY → ACTUAL_PRODUCTION | 安装验收、产量、利用率及进口替代 | 建设支出不证明供应链已回流 |
| 战略库存 STOCK ↔采购/释放 FLOW | 可用库存、品种、存放地及净变动 | 一次补库可抬进口，不等于长期全球化加深；授权采购不是入库 |
| 关税/补贴 AUTHORIZATION →生效→执行 | 产品、税率、日期、豁免、实际征缴/拨款 | 新闻意图不是全货物有效税率；本批不提供2026实时税率 |

## F. Causal mechanisms

**SUPPORTED_MECHANISM：**关税或许可改变相对到岸成本，企业可能换供应商、移最后加工环节或真正增设工厂。要区分路径，必须看上游进口、企业产能、国内增加值和最终销量。[S04/S05] 反证是没有生产扩张且进出口产品几乎对应；但汇总数据不足以单独证明逃税。

**CONDITIONAL_HYPOTHESIS：**友岸/近岸布局能减少某一地缘或距离暴露，却可能增加同区域自然灾害、成本或共同供应商集中。OECD全面回流情景使贸易与GDP下降，且韧性并非一致提高；这是模型反例，不是世界已承受相同损失。[S06]

**ALPHA_INFERENCE：**产业补贴可能吸引固定资产，但需求不足、工人/能源瓶颈和补贴竞赛会削弱回报；库存提供缓冲，同时增加融资与过时风险。需要现金、实际产出与停工数据验证，不能由“安全”目标推定效果。

## G. Competing explanations

| 假说 | 可区分的证据 | 本批判断 |
|---|---|---|
| A true deglobalization | 多年、跨周期的全球实际贸易/GDP下降，跨境增加值和生产网络同时缩减 | 本批不能据2025一年的资料支持广泛持续收缩；长期一致序列未重建 |
| B fragmentation | 跨阵营交易相对下降、阵营内/连接国上升，全球总量仍可增 | S04提供支持，依赖分组及反事实模型；当前力度未知 |
| C 战略部门脱钩、总量持续 | 高科技/安全产品受限，普通产品与服务继续跨境；产业新增量抵消限制 | WTO总量与M06规则可以并存；还需分产品增加值数据分解贡献 |
| “第三国都是转运” | 企业级原产地与加工、增加值、生产/FDI | S05对越南更支持真实重配而非简单转运；不能推广所有国家/产品 |

本批不预先选一个终局。现有证据更能排除“有摩擦即全球化结束”，仍无法判定未来程度。

## H. Current structure

WTO **2026-03版本**估计2025商品贸易量增长4.6%，2026基准预测1.9%；高油价情景更低，均不是2026全年实现值。[S01] 同版名义货物加商业服务为34.65万亿美元、增长7%；此次动态统计页给出34.89万亿美元、增长8%，页面未显示修订日期。本批不平均、不挑选，不借两个数制造增长加速；确切修订来源仍待核。[S01/S02]

UNCTAD2026报告新闻索引为2025 FDI约1.6万亿美元、增长6%；1月初估索引为增长14%，剔除渠道性流动后5%。正文读取失败，差异的基数/修订桥接未核。**只保留版本元数据与暂读值，不用于本批强结论**。[S07/S08] 截至检索日，全球贸易/GDP精确最新值、本地新增生产占比及真实迁移的FDI净额仍UNKNOWN；不从新闻金额拼出。
