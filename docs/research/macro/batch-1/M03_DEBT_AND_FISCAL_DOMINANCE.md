# M03 — Debt and Fiscal Dominance / 债务与财政主导

Research date: 2026-09-20, America/New_York. Codex/Alpha；仅研究，待审阅。这里讨论美国联邦债务及一般机制，不把不同国家、币种与制度当成同一案例。

## A. Executive definition

赤字是期间收支差；债务是某日存量。Gross federal debt 包含政府内部持有；debt held by the public 不含政府内部账户，却包含 Fed 持有；marketable Treasuries 是可交易证券口径，不能代替前两者。私营部门净可交易融资、总拍卖额及年度财政赤字也不同，现金余额变化、到期滚动和非预算融资事项都可形成差异。[S01/S02]

财政主导不是“债务很高”的同义词，而是财政融资需求约束货币政策/价格稳定选择的一种制度机制。可通过被迫维持过低融资成本、货币化或不充分财政调整表现出来；不能只用降息、QE 或一次长债上涨识别。金融抑制则指法规/资本限制等促使资金以受约束条件吸收政府负债，可与财政主导共存但不相同。低利率可能来自低增长、安全资产需求或独立货币政策。[S04/S05/S06]

Owner 链条：赤字→融资需要为 SUPPORTED_MECHANISM（非一比一现金等式）；发行→收益率 CONDITIONAL；货币财政互动 VERIFIED；→通胀/货币/资产方向 CONDITIONAL。高债务必然违约、Fed 必须降息、美元必然贬值均不是已验证结论。

## F. Causal mechanisms

一个简化的本币债务率恒等式是：债务率变化约由“有效利率减名义增长率”乘旧债务率，加初级赤字率及存量流量调整构成。这是会计分解，不是预测模型；需同期间、同口径，不能用当日十年收益率乘全部债务当当年利息。[S01]

| 机制 | 等级 | 反作用/确认/证伪 |
|---|---|---|
| 初级赤字及现金需求增加 → 净发行 → 私人吸收更多久期 → 期限溢价可能上升 | CONDITIONAL [S01–S03/S07] | 储蓄、安全资产需求、期限缩短、央行持有可抵消；确认期限净供给和多模型溢价；单次拍卖弱不能证明财政危机 |
| 融资利率上升 → 到期再融资平均成本逐步上升 → 净利息与未来融资压力 | WELL_ESTABLISHED 算术，幅度 CONDITIONAL [S01] | 长期限锁息、收入增长、财政调整；看实际期限分布和有效利率，不用全部存量立即重定价 |
| 财政不调整且融资要求约束央行 → 货币政策偏离价格稳定目标 → 通胀/货币信任压力 | CONDITIONAL / regime HYPOTHESIS [S04–S06] | 独立政策、税支出调整、增长改善；需制度/决策与通胀预期证据，债务高本身不足 |
| 监管迫使受约束机构持公债 → 相对市场回报被压低 → 政府融资成本转嫁 | CONDITIONAL，识别方法 CONTESTED [S06] | 银行可能自愿持有流动资产；需相对回报、强制配置和自由投资者对照，不把所有流动性监管称抑制 |
| 名义长期收益率变化 → 预期短率与期限溢价共同变化 | WELL_ESTABLISHED 分解框架，成分为模型估计 [S07] | 模型/调查结果可不同；十年率升不是必然加息预期升；名义减TIPS还含通胀风险及流动性差异 |

**ALPHA_INFERENCE M03-F1：**融资规模扩大但私人久期吸收稳定、预期通胀受锚定时，不足以宣布财政主导。依据S02/S03/S05/S07；替代解释为尚未显现的制度压力；若出现可核的融资目标约束政策、强制吸收及失锚证据，则该暂缓判断必须重审。

可研究的 regime，而非当前标签：

| Regime | 需要观察的识别证据 | 易混淆反例 |
|---|---|---|
| Fiscal tightening | 已实施税支出/初级余额改善，区分周期与结构 | 增长自然带来收入增加不是全由紧缩 |
| Monetary dominance | 政策坚持物价目标，财政承担调整 | 央行口头独立不等于所有未来决策独立 |
| Fiscal dominance pressure | 融资压力与政策偏离的制度证据 | 债务上升同时降息可能只是衰退 |
| Inflationary financing risk | 财政资金缺口、货币安排、预期/定价持续变化 | 一次能源价格冲击不是货币化证明 |
| Financial repression | 明确投资限制/资本限制、低于可比市场回报 | 安全/流动性服务本身可合理降低收益率 |

## G. Competing explanations

**期限溢价还是政策预期？**NY Fed 的 ACM 与调查/其他模型会给出不同成分；拟合收益率好不等于识别财政冲击正确。[S07] 本批不发布最新期限溢价点估计。

**债务带来通胀还是财政调整？**CBO 的现行法基线显示负担趋势；它不是财政主导假设的实证检验。BIS综述明确不同政策选择可改变利率、增长与通胀结果。[S01/S05] 不能从一个长期预测倒推出当前央行被迫宽松。

**金融抑制还是合理安全资产需求？**2026 IMF工作论文用受约束/非受约束投资者的需求差构造指标，其摘要报告历史关系；这依赖模型和反事实回报，不能排除所有审慎需求。全文直接读取失败，本文只使用摘要/检索节选，不复述其回归为已复现结论。[S06]

**本币债务不会技术违约？**本币发行能力降低一种融资约束，但法律债务上限、支付流程、政治决策和通胀仍是不同风险。既不能称违约必然，也不能称风险为零。[S01]

## H. Current structure

**CBO 2026年2月基线**预计 debt held by public 从2026年约 **101% GDP** 升至2036年 **120% GDP**；它是指定法律与经济假设下的预测，不是今天的实测债务率，更不是gross debt。[S01] 该报告不是九月最新经济政策全量更新，本档案明确保留这个资料时点差。

**Treasury 2026-08-03** 的Q3净可交易融资估计$739bn，反映现金流与期初现金变化；**08-05**安排以 bills/CMB 调节部分季节需要，并列出TIPS/票息券规模。[S02/S03] 发行期限构成决定私人承担的久期，不应只看一个总债务数。

财政主导当前状态为 **UNKNOWN / 未被本批证实**。已有风险渠道和历史制度案例，尚无足够本期识别证据。Fiscal Data日度页面直接读取返回403，本批没有伪造“9月20日最新债务金额”。本批也未取本周Fed持仓、实际利率与国债投标数据；不能用旧图宣布本周进入新regime。
